# Ícones das tecnologias

SVGs do [Devicon](https://github.com/devicons/devicon), versão fixada no commit
`7330accdbc47e2dc0c19789a48533c4a3c50fe58`, distribuídos sob a licença MIT
incluída em `public/licencas/devicon.txt` (também copiada para o build).
Os arquivos originais ficam em `icons/` nesse repositório.

Os nomes de arquivos foram simplificados para uso local. AWS usa a variante
`plain-wordmark`; as demais tecnologias usam `original`. Blade é representado
pelo símbolo do Laravel, framework ao qual pertence.

Os símbolos são exibidos como decoração ao lado do nome de cada tecnologia.
Os arquivos são incluídos pelo Vite e não dependem de um CDN em produção.
